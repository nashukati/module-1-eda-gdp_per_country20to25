# Module 1 — EDA + Preprocessing (Starter Kit)

This scaffold helps you produce a polished, portfolio-ready notebook for Module 1.

## Structure
```
ds_module1_starter/
├── notebooks/
│   └── EDA_template.ipynb
├── data/
│   ├── raw/           # put your CSVs here (e.g., winequality-red.csv, titanic.csv)
│   └── processed/     # cleaned/feature-ready outputs
├── src/
│   └── eda_utils.py   # helper functions for quick EDA
├── reports/
│   └── README.md      # paste final insights / executive summary
├── requirements.txt
└── .gitignore
```

## How to use
1. Place your dataset(s) in `data/raw/`.
2. Open `notebooks/EDA_template.ipynb` and follow the checklist cells top-to-bottom.
3. Save cleaned data to `data/processed/cleaned.csv`.
4. Commit + push to GitHub.
